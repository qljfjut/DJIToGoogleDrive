### ✨ 核心特性与亮点 (Highlights)

1. **🏷️ 品牌彻底定调升级为 DJIToGoogleDrive**：
   - 彻底消除与普通云盘的歧义，明确为 **Google Drive 官方生态专用**的一键导入极速同步工具。
2. **🌐 原生代码级中英双语国际化 (i18n & Localization)**：
   - 自动识别 macOS 操作系统语言偏好；
   - 偏好设置窗口内建中英语言切换器（跟随系统 / 简体中文 / English），全界面**毫秒级动态无缝切换**，无需重启。
3. **🔌 即插即感与双存储堆叠感知 (Dual-Storage Perception)**：
   - 接入 DJI 相机（Pocket 3/4、360 全景、Action）或插入 TF/SD 卡瞬间毫秒级识别；
   - 支持同时感知**机身内置存储**与**外置存储卡**，多盘自动归集。
4. **⚡ 16MB Chunk 工业级断点续传引擎**：
   - 专为数十至数百 GB 的 4K/8K 巨幅视频与全景素材优化；
   - 遇断网或电脑休眠后自动安全接续，无需重头再传；配备实时网速与精确 ETA 预估。
5. **☕ 系统防休眠与屏幕熄灭节能保护**：
   - 传输中基于 macOS 电源断言防止整机休眠，**允许屏幕完全黑屏熄灭**，通宵长传节能环保不伤屏。
6. **🛡️ 智能废片排查与卡内空间释放**：
   - 自动排查 0B 损坏文件与误触废片；
   - 支持在同步完成后直接从相机卡内单文件或批量物理删除，秒释数百 GB 宝贵卡内存储。
7. **🌟 深度联动「我有神器 · I Have An App」**：
   - 欢迎访问 [www.ihavean.app](https://www.ihavean.app) 与官方频道 [t.me/ihaveanapp](https://t.me/ihaveanapp)，探索更多 macOS 生产力神器与 DJI 影像工作流教程！

### 📦 下载与安装指引 (Installation)

1. 下载下方的 **`DJIToGoogleDrive-v1.2.0-macOS.zip`**；
2. 解压后将 **`DJIToGoogleDrive.app`** 拖入「应用程序」文件夹（或直接放在桌面）；
3. 双击打开，应用将自动静默常驻在屏幕**右上角菜单栏**（带有相机图标），插卡即用！

> 💡 **初次打开安全提示**：如遇到系统提示“无法验证开发者”，请按住键盘 `Control` 键右键点击应用选择「打开」，再点击「仍然打开」即可永久信任放行。
