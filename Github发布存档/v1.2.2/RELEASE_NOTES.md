# 🛸 DJIToGoogleDrive v1.2.2 官方优化版 (Official Release)

> 📌 **发布日期**：2026-09-10  
> 🏷️ **版本号**：`v1.2.2`  
> 💻 **支持系统**：macOS 13.0 (Ventura) 及更高版本（原生支持 Apple Silicon M系列 与 Intel 芯片）

---

### ✨ 核心特性与重大升级 (Highlights)

1. **🛡️ 启动台双图标彻底根治（隐身构建机制）**：
   - 溯源修复了历史打包流水线在桌面工作区遗留裸 `.app` 目录导致 macOS Launch Services 递归抓取并重复收录的死循环；
   - 组装过程全面转移至隐藏构建缓存区 `.build/`，并接入 `lsregister -u` 自动反注册守门员，保证启动台（Launchpad）与系统聚焦搜索全局永远仅且仅有唯一正式入口。
2. **📋 偏好设置模块层级顺畅重构**：
   - 顶部置顶 `1. 软件更新与版本`，第一眼即可核验版本状态与一键检查更新；
   - 中间高度内聚 Google 云存储设置服务流（`2. 凭证配置` ➔ `3. 账号授权` ➔ `4. 目标目录与过滤规则`）；
   - 低频项 `5. 界面语言` 优雅下沉，信息层级自然严密。
3. **✨ 更新亮点按需紧凑折叠（Zero Footprint by Default）**：
   - 更新内容默认收起，顶部首行紧凑配备 `[✨ 本版更新亮点 ▾]` 胶囊按钮，不占用多余垂直空间；
   - 点击按钮原地平滑展开 5 大核心亮点，再次点击随手收拢，随用随展。
4. **🌐 界面语言独立通栏自适应**：
   - 分段控制器独立另起一行并横向自适应通栏（`maxWidth: .infinity`），每项获得超过 150pt 的宽裕空间；
   - 彻底解决由于定宽挤压导致的 `English` 选项被右边界截断为 `Engli` 的显示缺陷。
5. **🎨 视觉深度去噪去重**：
   - 移除窗口内部重复的大标题块，整体内容上移约 70pt；
   - 移除各板块前多余的旋转与装饰小图标，1~5 项统一采用纯文字排版规范，现代沉稳。

### 📦 安装与升级方式 (Installation)

1. **已安装用户（一键自动升级）**：
   - 打开 App 偏好设置 ➔ 「1. 软件更新与版本」 ➔ 点击 **「🚀 一键自动更新并重启」** 即可无感自动升级！
2. **全新安装用户**：
   - 下载下方的 **`DJIToGoogleDrive-v1.2.2-macOS.zip`**；
   - 解压后将 **`DJIToGoogleDrive.app`** 拖入「应用程序」文件夹（/Applications）即可双击打开使用。
