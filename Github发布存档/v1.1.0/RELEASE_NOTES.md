# 🛸 DJIToGoogleDrive v1.1.0 里程碑发布说明

> 📌 **发布日期**：2026-09-09  
> 🏷️ **版本号**：`v1.1.0`

### 🔧 核心更新与缺陷修复
1. **修复窗口双向挤压裁切**：
   - 溯源定位到面板内容自然高度达 ~665pt，而窗口硬编码 600pt 导致顶部标题被削半、底部辅助栏被挤出屏幕外；
   - 窗口高度扩容至 645pt，垂直间距收敛至 8pt，顶部预留 20pt 避让箭头安全区，实现 100% 饱满展示。
2. **状态栏图标永久常驻**：
   - 废除无设备连接时隐藏状态栏图标的隐身逻辑，状态栏相机图标永久常驻右上角；
   - 增加断开与空闲状态微动画。
3. **系统级防休眠断言 (SleepAssertionManager)**：
   - 引入 `PreventUserIdleSystemSleep` 电源管理断言，阻止整机进入休眠，允许屏幕正常熄灭节能。
